# Data sources and redistribution boundary

This repository does not redistribute third-party raw observations.

## Wisconsin soybean survey
- Repository: Dryad
- DOI: https://doi.org/10.5061/dryad.2547d7wwt
- Use in this study: aphid and coccinellid observations used for retrospective next-visit forecasting analyses.

## Indiana soybean survey
- Repository: KNB Data Repository
- DOI: https://doi.org/10.5063/F15T3HPK
- Additional registration noted in the manuscript: https://doi.org/10.5063/F19K48D9
- Use in this study: reconstructed whole-plant aphid and adult/larval coccinellid observations.

## Wheat experiment
- Repository: Dryad
- DOI: https://doi.org/10.5061/dryad.2fqz612x5
- Use in this study: Sitobion avenae, Rhopalosiphum padi and total Harmonia axyridis observations used as a cross-system forecasting stress test.

## Boundary

The source repositories and original publications should be cited when the raw data are reused. Files in this GitHub repository are author-created documentation or derived materials only; no statement here changes the licensing terms of any source dataset.
